# Сибикс

Статическая верстка из Figma на HTML, CSS и JavaScript, без сборки и сторонних UI-библиотек.

## Страницы

- `index.html` — полноэкранная главная с адаптивной орбитальной композицией.
- `implementation.html` — внедрение Битрикс24.

## Запуск

Откройте `index.html` в браузере или запустите из папки проекта:

```sh
python3 -m http.server 8080
```

После этого откройте http://localhost:8080.

## Структура

- `css/style.css` — общие стили и адаптация; БЭМ, нативная вложенность CSS.
- `css/orbits.css` — положение декоративных орбит из макета.
- `css/fonts.css` — локальные начертания Onest.
- `js/main.js` — меню, диалоги, уведомление cookies, демонстрационный обработчик формы.
- `assets/` — локальные изображения WebP, векторные SVG и шрифты.

Контейнер страницы «Внедрение»: `max-width: 1752px`, `padding-inline: 16px`; полезная ширина — 1720px. Главная использует `100dvh`. Для мобильных предусмотрена отдельная композиция и сетки в одну/две колонки; для горизонтального экрана — компактная двухчастная главная.

## Что нужно для запуска заявок

Форма проверяет поля средствами браузера, но данные никуда не отправляет. Замените демонстрационный обработчик `submit` в `js/main.js` на запрос к своему API. Также добавьте утвержденные тексты политик, реальные адреса социальных сетей и содержание кейсов. В макете три одинаковые карточки «Зебра» — повторение сохранено. Ответы FAQ подготовлены для демонстрации и требуют редакционного согласования.

Выбор cookies хранится локально в браузере; аналитика и рекламные скрипты не подключены.
